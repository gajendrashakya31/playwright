# Playwright Project

This project uses [Playwright](https://playwright.dev/) for end-to-end testing.

## Getting Started

1. Install dependencies:
   ```powershell
   npm install
   ```
2. Run tests:
   ```powershell
   npx playwright test
   ```
3. View HTML report:
   ```powershell
   npx playwright show-report
   ```

## Project Structure
- `playwright.config.js`: Playwright configuration
- `tests/`: Test files

## More Info
See [Playwright docs](https://playwright.dev/docs/intro) for advanced usage.
